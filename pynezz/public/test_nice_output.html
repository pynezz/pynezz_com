How to make the output look nice

When dealing with certain output, like help descriptions that are of unknown length, things can get tricky.

![[Pasted image 20240621132359.png]]

Like this above

I'll need to figure out the string with the greatest length, and add the necessary padding between the command and the description (key, value).

To get that I'll use a simple for loop and store the greatest length found so far in the iteration, and return the greatest length when done:

func longestStringMap(m map[string]ICommand) int {
    var max int
    for k := range m {
        if len(k) > max {
            max = len(k)
         }
    }
    return max
}

Now we have the greatest length, which turns out to be 11 as of now.

In my [ansi-library](https://github.com/pynezz/pynezzentials) I have an AddPadding() function, which takes a string and adds padding to it. Originally I made it to use it in another function FormatRoundedBox() which makes the output at the beginning of the program in the first image.
